WOMIER Driver

Set up your keyboard software

This one-time setup downloads the official WOMIER driver, unpacks it and makes it run on Linux. It takes a few minutes on a normal connection.

  • 1Download the official driver from WOMIER (about 100 MB)
  • 2Unpack it and prepare it for Linux
  • 3Plug in your keyboard and start
